# UseCloud

Penyimpanan berkas pribadi di peramban. Pengguna membuat folder, mencari berkas, dan berpindah antara tampilan grid dan daftar.

Versi yang sedang tayang: [usecloude.vercel.app](https://usecloude.vercel.app)

## Isi aplikasi

- Folder, breadcrumb, dan panel detail berkas
- Pencarian nama berkas, folder, atau tipe
- Unggah berkas dan antrean unggahan
- Cadangan data di `backup.json`

## Menjalankan

Impor repositori ini ke Vercel, atau buka `index.html` lewat server statis. Gaya ada di `css/`, perilaku ada di `js/`.

## Teknologi

HTML, CSS, dan JavaScript. JSZip dipakai untuk mengemas berkas di sisi peramban.
